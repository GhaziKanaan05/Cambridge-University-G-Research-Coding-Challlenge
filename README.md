# Multicore Task Scheduling Optimisation

A heuristic scheduling algorithm developed for the
**G-Research Cambridge Coding Challenge**.

## Overview

The challenge involved scheduling tasks across multiple processor cores
while attempting to maximise the total reward generated by the system.

Each task had characteristics including:

- an arrival time,
- execution duration,
- base reward,
- time-dependent bonus,
- and processor-specific performance factors.

Rewards decreased when tasks were delayed, while additional bonuses were
available when tasks were scheduled sufficiently quickly.

## Approach

I developed a greedy scheduling heuristic that dynamically evaluates
each remaining task across every available processor.

For each possible task-processor assignment, the algorithm considers:

- the earliest possible start time,
- processor-specific reward factors,
- reward decay caused by waiting,
- whether the task can still receive its time bonus,
- proximity to the bonus deadline,
- and task duration.

The highest-scoring task-processor combination is selected at each
iteration, after which processor availability is updated and the
remaining tasks are re-evaluated.

## Result

**4th out of 50 participants** in the G-Research Cambridge Coding Challenge.
